Reports an outbound HTTP call (new URL(...), RestTemplate.getForObject, postForObject, exchange, getForEntity) on an endpoint parameter that was validated only with .startsWith(...) or .contains(...) on the raw URL string.

String checks on a URL can be bypassed: a value such as https://evil.com[@127.0.0.1 passes a prefix or substring test while a URL parser resolves a different host (CWE-918; compare CVE-2024-22243 in Spring Framework). Parse the URL first and validate its scheme and host against an allowlist.
